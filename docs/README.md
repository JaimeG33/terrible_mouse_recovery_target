# Documentation

## Usage Guide

For people running the tool:

- `usage-guide/STARTUP.md` - installation, first launch, and first-book setup.
- `usage-guide/TYPICAL_USAGE.md` - normal one-pass `record -> build` workflow.
- `usage-guide/COMMAND_REFERENCE.md` - current user-facing and diagnostic commands.
- `usage-guide/SCOPING_AND_TROUBLESHOOTING.md` - book/chapter scope and common failures.
- `usage-guide/RECOVERY_AND_FALLBACKS.md` - reset, Safe mode, Plain mode, and re-record guidance.
- `usage-guide/MULTI_BOOK.md` - per-book registry and switching behavior.
- `usage-guide/RUNTIME_AND_DATA_LAYOUT.md` - per-book runtime layout and which files are authoritative vs generated.
- `usage-guide/COMPATIBILITY.md` - supported McGraw Hill reader conventions and limitations.
- `usage-guide/SECURITY_AND_PRIVACY.md` - dedicated Chrome profile, local runtime data, and Git safety.
